Learning reduced models of Burgers’ equation

A numerical linear algebra study of Operator Inference: how the least-squares problem behind it is conditioned, solved and regularized, and when it recovers the operators that projection would give.

The idea in one paragraph

High-fidelity PDE solvers are expensive. A reduced-order model (ROM) replaces thousands of unknowns with a handful by projecting onto a low-dimensional basis. The classical (intrusive) way builds the reduced operators from the solver’s own matrices. Operator Inference (OpInf) instead learns them from simulation data by solving a linear least-squares problem. We’ll build both on the same test problem and use them to study the linear algebra: the SVD that defines the basis, and the least-squares solve that defines the model.

Setup

Test problem

Viscous Burgers’ equation on a 1D interval with fixed boundary conditions:

ut + u ux = ν uxx

Its quadratic nonlinearity matches the structure OpInf is designed for. A finite-difference discretization with n grid points gives the full-order model

dq/dt = A q + H (q ⊗ q),   q(t) ∈ ℝn

Reduced basis

Collect snapshots Q = [q(t1), …, q(tk)], take the SVD, and keep the first r left singular vectors as Vr. The reduced state is q̂ = VrT q.

Using the non-redundant quadratic terms, D has r + r(r+1)/2 columns, so its size and conditioning change quickly with r. That’s the heart of the project.

Questions we’ll answer

  1. Recovery. With clean data and exact derivatives, does OpInf reproduce the intrusive operators? How far off is it when derivatives come from finite differences of the snapshots?
  2. Conditioning. How does the condition number of D grow with r, and what drives it?
  3. Solvers. How do normal equations, Householder QR and the (truncated) SVD compare in accuracy and cost as D gets worse?
  4. Regularization. How should λ be chosen? We’ll compare the L-curve and generalized cross-validation against the stability-based criterion from McQuarrie, Huang & Willcox (2021).
  5. Robustness. How do noise in the snapshots and the choice of r affect long-time predictions beyond the training window?

Beyond Burgers’

Once the Burgers’ study is done, we’ll reuse the same pipeline (snapshots → SVD → least squares → ROM) on harder equations. Each one changes the linear algebra in a different way: the polynomial degree of the model sets how fast D grows with r, and the physics sets how fast the singular values decay. They’re listed in the order we plan to do them, easiest first.

Planned Korteweg–de Vries (KdV)

ut + 6 u ux + uxxx = 0periodic domain

The nonlinearity is quadratic, like Burgers’, so the model form and data matrix carry over unchanged. The solver needs care because the third derivative is stiff: Fourier pseudo-spectral in space with an exponential integrator (ETDRK4) in time. NLA angle: solitons travel without spreading out, so the singular values decay much more slowly than for Burgers’. A two-soliton collision is a good stress test for how large r has to be.

Planned Navier–Stokes (2D, incompressible)

ωt + u·∇ω = ν ∇2ω,   ∇2ψ = −ω,   u = (ψy, −ψx)vorticity–streamfunction form

In vorticity form the velocity depends linearly on ω, so the model is still quadratic. Start with a periodic box (Taylor–Green vortex or decaying turbulence) using a pseudo-spectral solver; a lid-driven cavity is a natural second case. NLA angle: the state now has 104–105 unknowns, so the snapshot matrix is tall and skinny. Computing the POD basis cheaply becomes its own problem: method of snapshots vs. randomized SVD. Each time step also needs a Poisson solve (FFT on the periodic box, conjugate gradient or multigrid in the cavity).

Planned Einstein field equations (reduced)

Gμν = 8π Tμνspherically symmetric, coupled to a massless scalar field

Full 3+1 numerical relativity is far beyond a course project, so we’ll do the standard 1+1 reduction: a massless scalar field collapsing in spherical symmetry (Choptuik’s problem). We’ll stay in the subcritical regime, where the field disperses and no black hole forms. The metric functions satisfy ODEs in r (the constraints) at every time step, and the scalar field evolves by a wave equation. NLA angle: the nonlinearity isn’t polynomial (metric functions appear in denominators), so OpInf’s polynomial form doesn’t fit directly. We’d need a lifting transformation: add auxiliary variables until the system becomes quadratic (Qian et al., 2020). This is the most demanding item on the list.

If time permits Nonlinear Schrödinger (NLS)

i ψt + ψxx + 2 |ψ|2 ψ = 0focusing, periodic domain

Easy to simulate with a split-step Fourier method. Splitting ψ into real and imaginary parts gives a real system with a cubic nonlinearity, so the model needs a cubic operator acting on non-redundant products q̂i q̂j q̂k. NLA angle: D then has r + r(r+1)(r+2)/6 columns (695 at r = 15, vs. 135 for a quadratic model), so conditioning and regularization become much harder. NLS also conserves mass and energy, which is a direct check on the learned ROM; Hamiltonian OpInf (Sharma, Wang & Kramer, 2022) preserves that structure.

If time permits Yang–Mills

Dμ Fμν = 0classical SU(2), on a lattice

The equations of motion have both quadratic and cubic terms in the gauge field, so the model needs both operators. The new difficulty is gauge freedom: many different field configurations describe the same physical state, so snapshots must be gauge-fixed first, or POD spends its modes on gauge artifacts instead of physics. A spatially homogeneous reduction turns the problem into a small chaotic ODE system, which would be a useful warm-up.

Risks and fallbacks

The learned ROM blows up in long-time prediction. That’s a result in itself: we’ll report the eigenvalues of Â and show how regularization changes them.

The Burgers’ solver takes longer than planned. Fall back to the 1D heat equation (linear, so Ĥ = 0) for the solver and conditioning study, and add Burgers’ once it works.

Not enough time for all regularization methods. The L-curve plus the stability-based criterion is the minimum; GCV is the first thing to cut.

The extra PDEs don’t all fit. The Burgers’ study comes first and is the core of the report. After that, KdV is the cheapest win since it reuses everything. If the Einstein reduction stalls (lifting or the constraint solve), we’ll document how far we got and move on to Navier–Stokes.

Tools

Python with NumPy and SciPy. We’ll write the least-squares solves ourselves, since they are the numerical linear algebra content, and use the Willcox group’s open-source opinf package only to check our results.
